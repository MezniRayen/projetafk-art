# AFK'Art by ARTECO 🎨

AFK’Art is an integrated digital platform developed as part of the PIDEV 3A integrated project at Esprit School of Engineering.

The platform connects artists, art enthusiasts, and investors through a modern and secure ecosystem that combines artwork management, user interaction, and artistic investment.

AFK’Art aims to transform the artistic market by offering artists more visibility, immersive experiences for visitors, and transparent investment opportunities for investors.

---

# 📌 Overview

The project was designed to solve the fragmentation of the artistic ecosystem where artists struggle to gain visibility, art lovers face limited experiences, and investors lack dedicated artistic investment platforms.

AFK’Art combines Web and Java technologies into one integrated solution.

---

# 🚀 Features

## 👤 User & Administration Management

* User authentication and authorization
* Role management (Admin / User / Artist)
* Account management
* Secure password handling
* Administrative action tracking

## 🎨 Artwork Management

* Create and manage artworks
* Like, comment, and favorite artworks
* Artwork interaction system
* Artwork categorization

## 💰 Investment Management

* Create artistic projects
* Investment and crowdfunding system
* Financial progress tracking
* Investment notifications

## 📊 Dashboard & Statistics

* Investment statistics
* Artwork engagement analytics
* User activity monitoring
